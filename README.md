# sharefile
P2P ShareFile without servers, direct peer to peer file transfer.

Testing with cells, networks, and proxies. In some cases it may not work with NAT traversal.

More secure than regular file sharing as it uses peer to peer connection.

Sensible with network security, no servers, no tracking, no ads, no malware.

No need to install any software, just open your browser at https://danielcdmconsultores.github.io/sharefile/

Note from dev: No responsaability for any files shared or any damage caused by the app.
We use peerjs for peer to peer connection. https://peerjs.com/
